# Local UI access

After Terraform has successfully provisioned the cluster and Argo CD has
synchronized its Applications, run:

```bash
scripts/expose-platform-uis.sh --environment dev
```

The helper uses `kubectl port-forward --address 127.0.0.1`, so it does not
create public Services, load balancers, or ingress rules. It exposes Argo CD,
the OpenTelemetry Demo storefront, and the shared Grafana, Prometheus, and
Alertmanager UIs. Loki and Tempo are available through Grafana Explore. It
prints only endpoints, never credentials.

Pass `--context` to select a kubeconfig context or `--workload-namespace` if a
workload uses a non-standard namespace. Keep the command running while using
the UIs and press Ctrl-C to cleanly close all port-forwards.

## GitOps convergence

Terraform calls the following read-only check after it creates the root Argo
CD Application. It can also be run directly to verify a dev deployment:

```bash
scripts/wait-for-gitops-convergence.sh --environment dev --timeout 1800
```

It discovers component and workload contracts from Git, then waits until every
generated Application is `Synced` and `Healthy`. The root Application's
post-sync dashboard readiness hook separately verifies all platform Grafana
dashboards through Grafana's API.

## Runtime dashboard credentials

Credentials are generated by the installed charts and are not committed to
Git. To display the currently configured Grafana password and the Argo CD
initial admin password on your terminal, run:

```bash
scripts/get-dashboard-credentials.sh --show-secrets
```

The script reads Kubernetes Secrets at runtime and never writes their values to
disk. Prometheus, Alertmanager, the OpenTelemetry Demo, Loki, and Tempo have no
platform-managed local username/password. If the Argo CD initial password was
changed, its current password cannot be recovered because Argo CD stores only a
password hash; reset it through the approved Argo CD administration process.
